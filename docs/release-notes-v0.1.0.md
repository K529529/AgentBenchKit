# AgentBenchKit v0.1.0

Initial V0 implementation on feature/v0-implementation.

- External Nexus and Codex Harnesses with a shared typed ModelSpec and isolated
  native config homes; manifest schema v2 stores requested and resolved conditions.
- Host and whole-Agent Docker execution, startup-only retries, process/container
  cancellation, fresh verification and complete bounded UTF-8 candidate snapshots.
- Eight internal micro_swe tasks, fixed planned denominators, conservative pass@k,
  immutable physical executions and rebuildable SQLite indexing.
- Versioned replay, evidence-based failure observations and manifest-first
  comparisons; subscription smoke and missing model controls are explicit limits.
- Optional four-dimension Judge with its own HTTP process deadline and versioned
  output, separate from deterministic correctness and Agent usage.
- Read-only local Viewer with runs, sample evidence and comparison pages.
- MIT license, Windows/Ubuntu CI, Docker boundary tests and real Agent evidence.

See implementation-status.md for exact PASS / FAIL / NOT RUN evidence and
limitations.md for known constraints. A release tag or package publication is not
created by this implementation branch; merge goes through a pull request.
